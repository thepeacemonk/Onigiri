Public integration APIs.

`bento.py` exposes the Bento Widgets integration and shared widget/notification
appearance helpers. `sidebar.py` exposes the sidebar registration API for other
add-ons. `widget_settings.py` provides the declarative Onigiri WebUI shell used
by Bento integrations: page/section/field schemas, autosave, native-value
bridging, and production-rendered preview documents.
